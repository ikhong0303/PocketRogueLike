# 냥코로그(가제) 시스템 기획서 · 완성형
### 포켓로그 구조 + 냥코 300종 리스킨 + 오토 턴제 전투

> 최종 완성 버전 기준으로 작성한 시스템 기획서. 냥코대전쟁 캐릭터 **300종 전량**을 수록하고, 포켓로그의 시스템을 그대로 계승하되 전투는 **케주얼 오토 턴제**로 진행한다. **100 스테이지 격파 = 승리.** 개발 범위(구현 우선순위)는 별도로 정한다.

## 3. 핵심 루프

### 3.1 런 루프
```
오토 턴제 전투(+캐치) → 승리 보상(돈·경험치) → 상점 3택1 드래프트(아이템·리롤·회복)
   → 파티·빌드 강화 → 다음 스테이지(도감↑ 난이도↑) → …
                                          └→ 6마리 전멸 → 런 종료 & 세이브 삭제
                                          └→ 스테이지 100 격파 → 승리(엔드리스 해금)
```

### 3.2 메타 루프
```
런 중 캐치·조우 → 스타팅/도감 해금 · 레벨 · 행운 · 바우처 → 다음 런 시작 전력↑ → 더 깊이 등반 → 반복
```
명제: **6마리 전멸(영구사망) × 300종 컬렉션 영구 성장**의 병렬.

### 3.3 스타팅 선택 (런 시작 · 코스트 예산제)
- **예산 10점.** 데려갈 냥코 코스트 합 ≤ 10. 파티 슬롯 6과 이중 제약.
- **초기 해금 = 도감 1·2·3**(각 코스트 1). 캐치·완주로 상위 도감 해금 시 코스트↑ → "강한 하나 vs 저렴한 여럿" 선택.
- **코스트 = ceil(도감번호 / 30)** → 1~10점.

| 코스트 | 도감 | 희귀도 |
|---|---|---|
| 1 | 1~30 | 기본·EX |
| 2 | 31~60 | EX |
| 3 | 61~90 | 레어 |
| 4 | 91~120 | 레어·슈퍼레어 |
| 5 | 121~150 | 슈퍼레어 |
| 6 | 151~180 | 울트라슈퍼레어 |
| 7 | 181~210 | 울트라슈퍼레어 |
| 8 | 211~240 | 울트라슈퍼레어 |
| 9 | 241~270 | 울트라슈퍼레어 |
| 10 | 271~300 | 레전드레어 |

- 조작: 방향키 커서 / SPACE 선택·해제 / ESC 취소. 예산 초과 선택 불가.

## 4. 전투 시스템 — 오토 턴제 + 캐치

### 4.1 오토 전투
- 아군 파티(최대 6) vs 스테이지 적. **턴 순서 = 스피드(도감 번호) 순**.
- 각 유닛 행동은 **AI 자동**(공격 기술 2종 중 상황 선택). 방어 스킬 = 상시 패시브. 디버프 스킬 = 조건/확률 발동.

### 4.2 캐치 (SPACE)
- 전투 중 야생 냥코에게 SPACE → 볼 투척.
- 성공률: `기본확률 × (1 − 적 잔여HP비율) × 타이밍보정 × 볼등급보정`. 적 HP를 깎고 타이밍을 맞출수록 성공률↑.
- 성공 → 파티 편입(§4.3). 실패 → 볼 소모, 전투 계속.
- 오토 전투에서 **플레이어의 유일한 실력 표현 = 캐치 타이밍** = 파티 업그레이드 수단.

### 4.3 파티(6) 관리 & 방출 (P / SPACE / ESC)
- 파티 상한 **6**. **박스 없음** → 하드 6슬롯, 캐치가 곧 파티 교체·업그레이드.
- 6마리 상태에서 캐치 성공 → **P**로 관리 모드.

| 키 | 동작 |
|---|---|
| 방향키 | 슬롯 커서 이동 |
| SPACE | 선택(방출 대상 / 확인) |
| ESC | 이전 · 취소 · 나가기 |

- 방출 확정 → 신규 냥코 편입. ESC 전면 취소 → 신규 냥코 놓아줌(기존 파티 유지).

### 4.4 인게임 조작 스킴

| 상태 | 키 | 동작 |
|---|---|---|
| 오토 전투 | SPACE | 볼 투척(캐치) |
| 오토 전투 | P | 파티 관리 진입(파티 6일 때) |
| 관리 모드 | 방향키/SPACE/ESC | 커서/선택/뒤로 |
| 스테이지 종료 | 방향키/SPACE | 드래프트 선택지 이동/확정 |

### 4.5 스탯 모델
- 능력치: HP, ATK, Speed, Level. (HP·ATK는 도감 값.)
- **Speed = 도감 번호 순서**: 번호가 클수록(강할수록) 선공. 방향은 데이터 상수 1개로 전환 가능.
- **레벨업 → HP·ATK 성장**: 성장 곡선은 희귀도/도감 구간 기반.

### 4.6 도감 스킬 → 턴제 매핑

| 도감 필드 | 턴제 처리 |
|---|---|
| 공격 스킬 2종 | 기술 슬롯 2개(자동, 속성 카운터 시 배율↑) |
| 방어 스킬 1종 | 상시 패시브(속성 피해 감쇄 / 파동·열파 무효 / 부활 / 살아남기) |
| 디버프 · 정지 | 대상 1~N턴 행동 불가 |
| 디버프 · 둔화 | 대상 Speed 일시 감소(턴 순서 후퇴) |
| 디버프 · 넉백 | 대상 다음 행동 지연/스킵 |
| 디버프 · 저주 | 대상 패시브·특수 무효화 |
| 디버프 · 공격력 저하 | 대상 ATK 일시 감소 |
| 디버프 · 사거리 감소 | 명중/우선도 보정으로 치환 |

## 5. 스테이지 설계

- 총 **100 스테이지**. 100 스테이지 격파 = **승리**(이후 엔드리스 해금).
- 원칙: **스테이지 상승 = 등장 적 도감번호 상승**(=강해짐). 난이도 커브 ≡ 도감 커브.

### 5.1 백본 생성 규칙 — 완전 무작위 · 매 런
- **매 런 시작 시 300종 중 100종을 무작위 추출** → **도감 오름차순 정렬** → 스테이지 1→100에 배치.
- 스테이지 k의 기준 적 = 정렬된 100종 중 **k번째**. 도감순 정렬이므로 난이도는 스테이지와 함께 상승.
- **런마다 적 구성이 달라진다**(로그라이트 리플레이성). 대신 스테이지 간 도감 점프 폭은 런마다 들쭉날쭉 — 무작위의 특성이자 재미 요소.
- 재현성: **시드 기반 추출** → 데일리 런·공유 런 가능(§10.8).

### 5.2 기대 난이도 분포 (평균)
균등 무작위 추출이라 **평균적으로는 스테이지 k ≈ 도감 3k** 부근을 지난다(실제 값은 런마다 변동). 아래는 기대값 기준 희귀도 흐름.

| 스테이지 | 평균 도감(≈3k) | 희귀도 |
|---|---|---|
| 1~3 | ~3~9 | 기본 |
| 4~16 | ~12~48 | EX |
| 17~33 | ~51~99 | 레어 |
| 34~50 | ~102~150 | 슈퍼레어 |
| 51~90 | ~153~270 | 울트라슈퍼레어 |
| 91~100 | ~273~300 | 레전드레어 |

### 5.3 야생 풀(캐치 대상)
- 각 스테이지 야생 스폰 = **직전 백본과 현재 백본 사이 도감 구간**(gap)에서 추출 → 백본에 안 뽑힌 종도 야생으로 등장.
- 한 런은 도감 1 → (그 런 최고 도감)까지 훑으므로 대부분과 조우, **여러 런에 걸쳐 300종 전부 수집 가능**.

### 5.4 보스 스테이지
- **보스 스테이지 = 10·20·30·…·100.** 각 보스 = 그 스테이지에 배치된 유닛(정렬된 100종 중 **10·20·…·100번째**) 그대로.
- 특별 처리는 **HP 2배**뿐. 매 런 무작위 추출이라 **보스도 매 런 바뀐다.**
- **처치 시 파티 전원 HP 완전 회복**(무료 회복 체크포인트). 평소 회복은 유료(§9).
- 최종 보스 = 스테이지 100 = 추출된 100종 중 최고 도감(런마다 변동).
- 추가 보상: 바우처·돈. 스테이지 100 격파 → 엔드리스 해금 + 보스 고유 아이템 상점 편입.

### 5.5 바이옴/테마
- 도감 오름차순 = 희귀도 오름차순이므로, 바이옴 전환을 §5.2의 희귀도 밴드에 맞춘다(기본→EX→레어→슈퍼레어→USR→레전드). 스테이지 진행이 곧 세계관 상승감.

## 6. 상점 드래프트 (포켓로그식, 스테이지 사이)
- 스테이지 종료마다 상점. **3택1**, 돈으로 **리롤·회복**.
- 드래프트 풀: 아이템(냥코 부착·스택), 볼 보충, 경제 강화, 파티 회복.
- 아이템은 특정 냥코에 부착·스택. 후반부 리롤 남용으로 고등급 파밍 가능(포켓로그 동일 텐션).

## 7. 유닛 로스터 (300종 전량)

| 구간 | 도감 | 역할 | 스피드(도감순) | 스타팅 코스트 |
|---|---|---|---|---|
| 기본 | 1~9 | 스타터 | 최하위(후공) | 1 |
| EX | 10~50 | 초반 주력 | 낮음 | 1~2 |
| 레어 | 51~100 | 범용 카운터 | 중간 | 2~4 |
| 슈퍼레어 | 101~150 | 특화 딜러·제어 | 높음 | 4~5 |
| 울트라슈퍼레어 | 151~270 | 고화력 에이스 | 매우 높음 | 6~9 |
| 레전드레어 | 271~300 | 최상위 | 최상위(선공) | 10 |

- 스탯이 도감순으로 지수 상승 + 스피드도 도감순 → **상위 도감 캐치 = 직접적 업그레이드**(먼저·세게). 6슬롯 하드 캡과 맞물려 "캐치로 파티를 갈아끼우는" 로그라이트 재미.

## 10. 유니티 구현 아키텍처

### 10.1 데이터 — ScriptableObject + Addressables
- `CatUnitSO`: 도감번호·HP·ATK·희귀도·기술2참조·패시브1·디버프1·타깃속성마스크. **Speed·스타팅 코스트는 도감번호 파생** — `Cost = CeilToInt(DexNo/30f)`, 필요 시 `costOverride`.
- `MoveSO`(재사용 기술 모듈), `EnemySO`, `ItemSO`, `TraitSO`, `BiomeSO`, `RaritySO`, `StageDef`.
- **300종은 도감 CSV/JSON → SO 자동 임포트**(§부록).

### 10.2 스테이지 생성 — StageGenerator
```
// 매 런 1회: 시드로 재현 가능
var backbone = Enumerable.Range(1, 300)
    .OrderBy(_ => rng.Next()).Take(100)   // 무작위 100 추출
    .OrderBy(dex => dex).ToList();          // 도감 오름차순 정렬
int BackboneDex(int stage) => backbone[stage - 1];
```
- 야생 풀 = `(BackboneDex(stage-1) … BackboneDex(stage)]` 구간(gap)에서 스폰.
- `bool IsBoss(int stage) => stage % 10 == 0;` → HP 2배 + `OnBossDefeated: HealParty(full)`.
- 보스 = `backbone[stage-1]`(10·20·…·100번째 유닛), 스폰 시 HP 2배. 최종 보스 = `backbone[99]`(런마다 변동).
- `int totalStages = 100; bool win = clearedStage == 100;`

### 10.3 전투 — TurnManager
- Speed(도감순) 정렬 큐: `units.OrderByDescending(u => u.DexNo)` (방향 상수화).
- AI가 MoveSO 2개 중 자동 선택 → 데미지/효과. 속성 카운터 = TraitMask 비트 연산.
- `EffectSystem`: 정지·둔화·저주·넉백을 턴 지속형 상태 컴포넌트로 부착.

### 10.4 캐치·입력 — BattleInputState
```
enum BattleInputState { Auto, CatchThrow, PartyManage }
Auto      : [SPACE]→CatchThrow  | [P](파티==6)→PartyManage
CatchThrow: 타이밍 판정 → 성공? → (파티<6 ? 편입 : PartyManage) : Auto
PartyManage: 방향키=커서, [SPACE]=방출 확정, [ESC]=취소 → Auto
```
- 캐치 성공률은 순수 함수 분리(적 HP비율·타이밍·볼등급 입력).

### 10.5 스타팅 — StarterSelectState
- MetaSave 해금 목록에서 코스트 예산(10) 내 조합. 방향키/SPACE/ESC. 초과 선택 비활성.

### 10.6 성장 — 레벨 곡선
- `HP += curveHP(level, rarity); ATK += curveATK(level, rarity);` (AnimationCurve/테이블).

### 10.7 세이브 — 런/메타 분리
- `RunSave`(파티6·스테이지·돈·볼·아이템; 전멸 시 파기) vs `MetaSave`(300종 해금·레벨·행운·바우처; 영구).

### 10.8 RNG
- 시드 기반(캐치 판정·야생 조우·상점·특급) → 데일리 런·재현성.
